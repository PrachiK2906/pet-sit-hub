# Pet-sit Hub

Mobile app for a pet care network, prototyped in Android Studio, connecting pet parents with trusted sitters. Features dual-role profiles, real-time GPS tracking, health monitoring, and emergency telemetry services. (2024-2025)

## Tech

`Android Studio` `Mobile UX` `User Research` `Prototyping`
